云间 v0.3.0：歌词、封面与单曲移动 / 删除。Flutter 手机直连百度网盘，无需部署后台。

- 歌词逐行高亮，点击时间歌词跳转播放；支持 LRC、纯文本与常见中文编码。
- 读取常用 MP3 / FLAC 内嵌资料，或歌曲同目录的同名 LRC、同名图片与 cover / folder / front 图片，不递归扫描网盘。
- 从手机导入歌词和封面；手动搜索 LRCLIB、MusicBrainz / Cover Art Archive 并选择对应版本，只发送输入的歌名 / 歌手，不发送百度凭据或音频。
- 资料本机缓存，重启和断网后可查看；缓存封面显示于播放器与系统媒体信息。在线命中率和网络可用性不保证，手机导入可作为补充。
- 单首网盘歌曲移动到指定音乐目录内的其他文件夹，目标同名不覆盖，成功后更新队列、本地副本目录与资料缓存。
- 删除网盘音频前显示歌名和完整路径，已下载的本地副本保留。歌词、目录封面等旁置文件不会随音频移动或删除。
- 保留指定音乐目录、歌手 / 分类子目录、在线播放、持久下载、手机音乐上传、收藏、播放队列和后台控制。

Android 8.0 及以上，安装附件 cloud-music-android.apk，可覆盖之前相同个人签名的版本。首次连接需配置自己的百度 AppKey / SecretKey 并授权，随后指定 /音乐 等具体目录；不会读取网盘根目录 /。

音乐标签仅解析前 2 MB，歌词 256 KB、图片 5 MB；其他格式可使用同目录文件、导入或手动匹配。原创试听曲为器乐，歌词页显示的是演示说明。

移动 / 删除使用同步接口并检查逐文件结果；结果无法确认时请先刷新核实，不自动重试。传输需要保持 App 运行，尚不提供跨进程断点续传。下载和资料保存在 App 内，卸载 / 清除数据会移除。

验证包含静态分析、74 项自动测试、Android release 构建、Android 15 模拟器播放 / 后台控制和重启断网本地播放 / 缓存资料检查，以及 iOS 无签名编译。没有连接真实百度账号，实际权限、读写速度与中文资料命中率仍需在自己的设备上联调。iOS 安装仍需 Apple 签名。
