云间 v0.5.0：歌曲自动缓存。

- 在线播放自动保存歌曲，完整接收并通过长度检查后，下次优先从本地播放，无需重新加载网盘音频。
- 缓存歌曲按原歌手 / 分类目录显示在“本地”，重启或断网后仍可播放；播放页显示“歌曲缓存 · 离线播放”。
- 首页右上角新增“歌曲缓存”，查看占用和数量，并可确认后清除。清除会停止播放，保留手动下载、歌词和封面。
- 默认缓存上限 1 GB，按最近使用顺序自动清理，保护当前播放文件。超大歌曲仍可在线播放，不加入缓存。
- 已缓存歌曲手动下载时直接复制，不重复请求音频。下载与自动缓存独立，清除缓存不影响长期下载。
- 边接收边播放，拖动到尚未缓存的位置时请求对应分段；不完整文件不作为缓存，切歌 / 停止取消未完成缓存。
- 保留播放页封面 / 歌词滑动、手动搜索歌词 / 封面、百度网盘直连、指定目录、上传、移动 / 删除及后台播放。

Android 8.0 及以上，安装 cloud-music-android.apk，使用固定个人签名，可覆盖升级旧正式版。无需卸载，原配置与手动下载保留。缓存是 App 私有数据，卸载或清除应用数据会删除。想永久保留请手动下载。

设备检查使用内置原创音频走缓存播放链路；真实百度账号权限、速度和格式仍需自己的手机验证。iOS 提供无签名编译产物，不是可直接安装的 iPhone 包。
