云间 v0.4.0：播放页滑动歌词与搜索优化。

- 歌词直接显示在播放页，左右滑动切换封面 / 歌词，也可点击下方标签；进度和播放控制共用。
- 左上角菜单只保留“搜索歌词”和“搜索封面”，移除手机资料导入 / 添加入口；升级前已缓存资料保留。
- 搜索初值清理曲序、音质标记与文件名中的歌手前缀，嵌套专辑优先使用上层歌手目录。无结果时自动放宽关键词，仍由你选择对应版本。
- 歌词、音乐资料和封面图片服务独立排队与限流；短暂网络 / 服务故障最多重试一次，遵守 Retry-After，显示超时、限流与缺少封面的区别。
- 合并重复请求，成功候选缓存 20 分钟；封面缩略图缺失时尝试较小图片 / 对应专辑组。
- 选中封面下载失败时保留候选，可重试或换版本；成功前不替换已有资料。
- 保留百度网盘直连、指定音乐目录、在线播放 / 下载 / 上传、单曲移动 / 删除及后台播放。

Android 8.0 及以上，安装 cloud-music-android.apk，可覆盖之前相同个人签名的版本。

验证包含本地静态分析、84 项自动测试、Android release、Android 15 模拟器播放 / 后台控制 / 左右滑动 / 重启断网缓存检查，以及 iOS 无签名编译。未连接真实百度账号。第三方网络可达性、中文歌曲命中率和版本仍需你的手机确认，不保证接口始终可用。iOS 安装仍需 Apple 签名。
