云间 v0.2.0：歌手目录、离线下载和手机上传。Flutter 客户端直接连接百度网盘，无需部署后台。

- Android 8.0 及以上；安装附件 `cloud-music-android.apk`。
- 按真实文件夹展示歌手和专辑，可将 `/音乐` 等目录设为音乐库入口。
- 在线播放，或下载后在“本地”按目录听歌；默认优先使用本地副本。
- 系统文件选择器多选手机音频，上传到当前网盘目录；支持新建歌手目录，同名文件不覆盖。
- 传输进度、取消、失败重试；不完整下载不进入本地音乐库。
- 保留搜索、收藏、队列、进度、随机和循环播放。
- 后台播放、系统媒体控制、上一首/下一首及播放位置恢复。
- 安装后先点“晨光”或“潮汐”体验原创合成音频；连接真实网盘时，在“连接”中填写自己的 AppKey 和 SecretKey，并在百度官方页面完成授权。
- 没有内置百度凭据；个人配置与 token 仅保存于设备安全存储。只导入 access token 时无法自动刷新。

下载保存在 App 内，卸载/清除数据会移除。传输时请保持 App 运行；跨进程断点续传和系统 Downloads 导出暂未提供。

验证包含静态分析、自动测试、Android release 构建与 Android 15 模拟器播放/后台控制，以及下载后结束进程、禁用网络再从本地文件播放。iOS 无签名编译产物保留在 Actions；安装到 iPhone 仍需要 Apple 开发者签名。

实际可访问的网盘目录、读写权限、配额、音频格式和传输速度需要使用者在自己的账号和设备上确认。本次没有进行真实百度账号联调。
