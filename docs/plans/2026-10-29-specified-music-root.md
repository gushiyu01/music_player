# 指定音乐目录

用户要求：只访问自己指定的网盘目录，其下的子目录就是分类或歌手目录。

连接成功后先进入目录设置状态，用户手动填写 `/音乐` 等绝对路径。拒绝 `/` 和包含 `.`、`..` 或非法字符的路径；支持整理多余斜杠。未设置目录时不请求网盘文件列表。旧版未保存目录或保存 `/` 的配置迁移到设置状态。

首页只分页加载指定目录的直接子项。进入子目录时才读取它，不递归扫描。返回上级止于音乐根目录。改变目录入口、上传目标和新建目录均经过同一范围检查；旧上传任务不能在更换入口后重试到范围外。已下载的本地音乐继续保留。

实施与验证：

1. 增加路径规范化、范围判断和控制器启动迁移；覆盖首次连接、旧配置、越界、分页与延迟响应。
2. 增加指定目录提示和输入校验，调整导航与分类文案，验证上传入口和根目录返回边界。
3. 运行格式、静态分析和完整测试，提交 GitHub Actions 构建；完整通过后发布同一 APK 并发送企微通知。
